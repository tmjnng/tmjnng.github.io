# JLPT Exam Skill

## 説明
このスキルは、JLPT（日本語能力試験）刷題システムの使用支援と、日本語学習に関する様々な機能を提供します。N5からN1までの各级別の Vocabulary、文法、読解、リスニングの問題練習をサポートします。

## 機能

### 刷題システム関連
- システムの起動方法と使い方の手順説明
- 練習モードと試験モードの違いと利用方法
- 統計データの解釈と学習進捗の確認方法
- 問題データの編集・追加方法

### JLPT試験関連
- 各級（N5〜N1）の概要と合格率
- 出題傾向と対策方法
- 試験時間配分と攻略テクニック
- 単語・文法・読解・リスニングの各パート対策

### 日本語学習関連
- 単語の暗記方法和 suggestions
- 文法の理解と応用
- 読解問題の解き方
- リスニング力の向上方法

## 用途
以下を行う際にこのスキルを使用してください：
- JLPT刷題システムの使い方を知りたい
- JLPT試験の対策をしたい
- 日本語の単語・文法を学びたい
- 練習問題の解説を求めたい
- 学習進捗を確認したい

## 使用例
```
「JLPT N5の試験対策を教えてください」
「この問題の解き方を教えてください」
「システムの問題データを追加する方法を教えて」
「単語の暗記有什么好方法吗（N5レベル向け）」`
```
