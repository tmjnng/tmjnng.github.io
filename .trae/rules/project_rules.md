# 项目规则 (project_rules.md)

## 项目概述
- **项目名称**：在线工具集合与博客系统
- **项目路径**：`C:\Users\NEWCON\Desktop\vbs\tool-workspace\tmjnng.github.io`
- **主要功能**：
  - 根目录主页（工具集合导航页面）
  - 博客系统（基于Hexo）
  - JLPT日语刷题系统（N5-N1级别）
  - 工具集合（AES加密、Base64编码、JSON处理等）

  - MiniCut在线视频编辑器（类似剪映功能）

  - Sudoku数独游戏（经典益智游戏）
  - Gobang五子棋游戏（经典策略游戏）
  - MathGrade数学学习系统（分年级数学学习，支持G1-G9）
  - 快乐学习儿童启蒙应用（汉字学习、数学启蒙，适合3-6岁）

## 开发规范
### 1. 代码规范
- **JavaScript**：使用ES6+语法，遵循标准编码规范
- **HTML/CSS**：语义化标签，清晰的样式结构
- **JSON**：格式正确，缩进一致（2空格）
- **文件编码**：UTF-8编码

### 2. 命名规范
- **文件命名**：小写字母 + 连字符，如 `aes-tools.js`
- **变量命名**：驼峰式，如 `currentQuestionIndex`
- **函数命名**：驼峰式，如 `loadQuestionsFromJSON`
- **常量命名**：大写字母 + 下划线，如 `MAX_QUESTIONS`

### 3. 测试规范
- **测试目录**：对应模块的 `test/` 目录
- **测试文件**：`test_*.html` 或 `*_test.js`
- **测试覆盖**：核心功能应有测试用例
- **测试执行**：优先使用浏览器端测试

### 4. 数据库规范
- **JLPT系统**：使用IndexedDB存储数据
- **初始化**：确保数据库初始化完成后再操作
- **错误处理**：完善的错误处理机制
- **数据备份**：重要数据应有备份策略

### 5. 数据库设计工具规范
- **数据库类型**：支持通用SQL、Oracle、PostgreSQL、MySQL、SQL Server
- **数据类型映射**：根据不同数据库系统自动映射数据类型
- **导出功能**：支持导出为JSON和多种数据库的SQL脚本
- **表设计**：支持拖拽布局、字段编辑、关系定义
- **本地存储**：设计数据保存在localStorage中

### 6. MiniPen在线代码编辑器规范
- **编辑器功能**：支持HTML、CSS、JavaScript三种代码编辑
- **实时预览**：代码修改后自动更新预览，支持手动刷新
- **控制台输出**：捕获并显示JavaScript控制台输出（log、error、warn、info）
- **项目管理**：支持新建、保存、导出、导入项目
- **本地存储**：项目数据保存在localStorage中
- **快捷键支持**：Ctrl+S保存，Ctrl+Enter运行代码
- **面板折叠**：支持折叠/展开各个编辑器面板
- **全屏预览**：支持全屏预览功能
- **错误处理**：捕获并显示JavaScript执行错误
- **时间显示**：显示当前时间和外网IP地址

### 7. SnapPicEdit在线图片编辑工具规范
- **核心功能**：支持图片上传、分辨率调整、背景色设置、缩放裁剪、文字水印、图片压缩、格式转换、主色调提取、自动抠图、缩略图生成、二维码添加、批量导出
- **实时预览**：编辑操作实时反映在预览中
- **本地处理**：所有图片处理在浏览器端完成，不依赖后端服务
- **国际化支持**：支持英语、中文、日语三种语言
- **本地存储**：用户设置保存在localStorage中
- **性能优化**：使用Canvas API进行高效图片处理，避免内存泄漏
- **浏览器兼容**：支持Chrome、Firefox、Safari等主流浏览器
- **批量处理**：支持多图片批量上传和导出

### 8. MiniPhotoEdit在线图片编辑器规范
- **核心功能**：支持图像上传、裁剪、滤镜、调整（亮度/对比度/饱和度）、旋转翻转、文字添加、绘图工具、撤销重做等功能
- **图像处理**：所有图像处理在浏览器端完成，不上传至服务器
- **画布技术**：使用Canvas API进行图像处理和编辑操作
- **模块化设计**：功能分离到独立的JS模块（crop-tool.js, filter-tool.js, text-tool.js, draw-tool.js）
- **用户界面**：直观的工具栏和属性面板，支持三语言国际化
- **性能优化**：合理使用Canvas分层技术，避免大图像处理时的性能问题
- **撤销重做**：支持多步历史记录管理
- **文件格式**：支持常见图片格式（JPEG、PNG、WebP等）的导入导出

### 9. MiniCut在线视频编辑器规范
- **核心功能**：支持视频/图片导入、时间轴编辑、特效添加、转场效果、文字叠加、音量控制、视频导出等功能
- **视频处理**：所有视频处理在浏览器端完成，不上传至服务器
- **Canvas技术**：使用Canvas API进行视频帧处理和特效应用
- **模块化设计**：功能分离到独立的JS模块（app.js, media-manager.js, timeline.js, effects.js, exporter.js）
- **用户界面**：专业的时间轴编辑界面，支持三语言国际化
- **性能优化**：采用分段处理和内存管理，避免大视频文件处理时的性能问题
- **格式支持**：支持常见视频格式（MP4、WebM等）和图片格式的导入导出

### 10. weedit微信公众号图文排版工具规范
- **核心功能**：支持安全粘贴、样式模板（标题1、正文、引用、分割线、注释）、HTML清洗与标准化、一键复制、响应式预览模拟、本地草稿自动保存
- **安全粘贴**：自动清除粘贴内容中的class、id、script、style标签，将样式转为内联style
- **HTML标准化**：仅保留微信支持的标签（p, h1-h3, img, strong, em, ul/ol/li等），所有样式转为内联
- **实时预览**：右侧预览区模拟iOS阅读界面（宽度375px，背景#f5f5f5）
- **本地存储**：使用localStorage自动保存草稿（每30秒），页面刷新后恢复
- **一键复制**：支持现代Clipboard API，降级到execCommand
- **纯前端实现**：所有功能在浏览器端完成，无后端依赖
- **响应式设计**：适配不同屏幕尺寸

### 11. Sudoku数独游戏规范
- **核心功能**：经典数独游戏，支持4种难度等级（简单、中等、困难、专家）

- **错误检测**：自动检查行列宫重复，支持高亮显示错误
- **计时功能**：实时显示游戏用时
- **本地存储**：保存用户设置和每日提示次数
- **UI特性**：渐变背景动画、玻璃拟态效果、现代化按钮样式
- **响应式设计**：适配不同屏幕尺寸
- **纯前端实现**：所有功能在浏览器端完成，无后端依赖

- **错误检测**：防止无效落子，支持高亮显示获胜线路

- **UI特性**：现代化棋盘设计、动态落子效果

### 13. MathGrade数学学习系统规范
- **MathGrade数学学习系统规范**
- **架构设计**：采用分年级架构，每个年级独立但共享底层引擎
- **核心组件**：
  - GradeApp.js: 应用控制器，自动检测年级、初始化主题
  - KnowledgeGraph.js: 知识图谱渲染器
  - QuestionGenerator.js: 题目生成器（模板引擎）
  - ProgressTracker.js: 进度追踪器
  - TreeNavigator.js: 左侧树形导航
  - FormulaRenderer.js: KaTeX公式渲染封装
  - CanvasBoard.js: 草稿板组件（支持绘画、橡皮擦、保存PNG）
  - ExercisePanel.js: 习题面板（选择题、填空题、反馈系统）
- **存储规范**：
  - 使用GradeStorage实现年级隔离的localStorage存储
  - 数据前缀格式：`math_g{grade}_`
  - 自动保存学习进度、掌握度、错题本
- **题目模板**：
  - 支持变量随机生成（range, divisible, decimal）
  - 支持约束条件（constraint）
  - 支持多种题型（fillblank, choice）
  - 支持LaTeX公式渲染
- **年级主题**：
  - G1-G2: 幼儿友好，大字体，鲜艳色彩
  - G3-G4: 小学中年级，活泼但稍稳重
  - G5-G6: 小学毕业，准备衔接初中
  - G7-G9: 中学，学术感增强，中考模式
- **Service Worker**：支持离线缓存，缓存静态资源和CDN资源

### 14. 快乐学习儿童启蒙应用规范
- **核心功能**：汉字学习（200字，Level 1-2）、SVG笔顺动画、数学加减法（0-20）、游戏化学习
- **技术架构**：单文件HTML应用，内联CSS和JavaScript，PWA支持
- **汉字学习**：
  - 200个常用汉字，分Level 1（基础）和Level 2（家庭）
  - SVG路径动画展示笔顺
  - 支持播放、暂停、重播控制
  - 语音朗读（Web Speech API）
- **数学学习**：
  - 0-20加减法，三级难度（0-5, 6-10, 11-20）
  - 具象化动画（Emoji移动合并、物品飞走效果）
  - 连击系统（Combo）和金币奖励
  - 错题记录和薄弱点分析
- **游戏模式**：
  - 看图识字：匹配图片和汉字
  - 听音选图：根据读音选择正确图片
- **进度报告**：
  - 汉字学习进度环（CSS conic-gradient）
  - 数学正确率、金币、连击统计
  - 薄弱点提示
  - 学习热力图
- **存储规范**：
  - localStorage存储学习进度
  - 支持隐私模式降级到内存存储
  - 数据前缀：`kids_`
- **无障碍支持**：prefers-reduced-motion减少动画
- **UI设计**：大按钮（100px+）、鲜艳色彩、适合3-6岁幼儿

### 14. 安全规范
- **加密操作**：使用Web Crypto API，避免不安全的加密实现
- **用户数据**：本地存储，不发送到服务器
- **输入验证**：对用户输入进行适当验证
