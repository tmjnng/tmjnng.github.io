# JLPT日语刷题系统使用指南

## 项目简介

这是一个基于客户端技术实现的JLPT日语刷题系统，无需后端支持即可在浏览器中运行。系统支持N5和N4级别的词汇和语法练习，提供练习模式和考试模式，并记录用户的学习进度和统计数据。

## 功能特点

### 核心功能
- **级别选择**：支持JLPT N5和N4级别
- **练习模式**：逐个题目练习，即时反馈答案正确性
- **考试模式**：模拟考试环境，30分钟倒计时
- **进度跟踪**：记录每个级别的练习进度和正确率
- **统计分析**：提供总练习数、正确率、今日练习等统计信息
- **随机出题**：每次练习随机排序题目，避免记忆答案顺序

### 技术特色
- **无后端架构**：完全基于前端技术实现，无需服务器支持
- **数据持久化**：使用IndexedDB存储题目数据和用户进度
- **习题集JSON化**：题目数据单独存储在JSON文件中，便于维护
- **响应式设计**：适配不同屏幕尺寸的设备
- **错误处理**：完善的错误处理机制，确保系统稳定性

## 系统架构

### 文件结构
```
exam/
├── index.html              # 主页面
├── css/
│   └── style.css          # 样式文件
└── js/
    ├── app.js             # 主应用逻辑
    ├── database.js        # 数据库管理
    └── questions.json     # 题目数据JSON文件
```

### 核心模块

1. **用户界面层** (`index.html`)
   - 级别选择面板
   - 练习模式界面
   - 考试模式界面
   - 统计面板

2. **应用逻辑层** (`app.js`)
   - 用户交互处理
   - 问题显示和导航
   - 答案提交和反馈
   - 计时器管理

3. **数据管理层** (`database.js`)
   - IndexedDB数据库初始化
   - 题目数据加载和存储
   - 用户进度记录和更新
   - 统计数据计算

4. **数据源** (`questions.json`)
   - 所有JLPT题目数据
   - 包含题目、选项、正确答案和解释
   - 按级别和类型分类

## 安装和运行

### 方法一：直接打开

1. 下载项目文件到本地
2. 直接用浏览器打开 `exam/index.html` 文件
3. 系统会自动初始化并加载题目数据

### 方法二：本地服务器（推荐）

1. 下载项目文件到本地
2. 在 `exam` 目录下启动本地服务器：
   ```bash
   # 使用Python 3
   python -m http.server 8000
   
   # 使用Node.js
   npx http-server -p 8000
   ```
3. 在浏览器中访问 `http://localhost:8000`

## 使用方法

### 1. 级别选择

- 打开系统后，首先进入级别选择界面
- 点击想要练习的级别卡片（N5或N4）
- 系统会自动加载该级别的题目并进入对应的模式

### 2. 练习模式

- 点击导航栏的「练习模式」按钮进入
- 系统会随机显示一道题目
- 选择一个答案选项
- 点击「下一题」按钮继续练习
- 系统会自动记录答题情况

### 3. 考试模式

- 点击导航栏的「考试模式」按钮进入
- 系统会开始30分钟倒计时
- 点击「下一题」按钮切换题目
- 所有题目完成后，点击「提交考试」按钮
- 系统会计算考试结果并显示得分

### 4. 查看统计

- 点击导航栏的「统计面板」按钮进入
- 查看总练习数、正确率、今日练习等统计信息
- 数据会实时更新，反映最新的学习情况

## 习题集维护指南

### 1. 修改题目数据

所有题目数据存储在 `exam/js/questions.json` 文件中，可以直接编辑该文件来维护习题集。

### 2. 题目数据格式

每个题目的数据格式如下：

```json
{
  "level": "N5",
  "type": "vocab",
  "question": "このりんごは <strong>甘い</strong> です。",
  "option_a": "あまい",
  "option_b": "しおからい",
  "option_c": "からい",
  "option_d": "すっぱい",
  "correct_answer": "A",
  "explanation": "「甘い」的平假名是「あまい」，意思是甜的。"
}
```

### 3. 添加新题目

1. 打开 `questions.json` 文件
2. 在 `questions` 数组中添加新的题目对象
3. 确保所有字段格式正确
4. 保存文件并刷新浏览器页面

### 4. 修改现有题目

1. 打开 `questions.json` 文件
2. 找到要修改的题目
3. 修改相应的字段
4. 保存文件并刷新浏览器页面

### 5. 删除题目

1. 打开 `questions.json` 文件
2. 找到要删除的题目
3. 删除该题目对象
4. 保存文件并刷新浏览器页面

### 6. 立即更新数据

如果需要在不刷新页面的情况下更新题目数据，可以在浏览器控制台中执行：

```javascript
db.reloadQuestions();
```

## 注意事项

1. 系统使用IndexedDB存储数据，清除浏览器缓存会导致学习进度丢失
2. 推荐使用现代浏览器以获得最佳体验
3. 考试模式的计时器功能需要浏览器支持Web API
4. 习题集维护时请确保JSON格式正确，否则可能导致系统无法正常加载题目
